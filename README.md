# 이웃집 개발자

결제·정산 백엔드 설계를 **실제로 돌려 보이는** 기술 쇼케이스 사이트.

방문자가 샌드박스 결제를 직접 실행하면 상태 전이·웹훅 수신·멱등성 방어가
3D 그래프 위에 실시간으로 그려진다. 결제 성공만이 아니라 **중복 요청이 튕겨나가는 것,
웹훅이 두 번 와도 원장이 이중 반영되지 않는 것**을 방문자가 직접 재현할 수 있다.

## 구성 (예정)

```
apps/
  web/    Next.js  — 3D 쇼케이스 · 사례 · 문의
  api/    NestJS   — 결제 샌드박스 · 웹훅 수신 · 상담 전 자가진단
```

## 상태

기획 확정, 구현 착수 전. 초기 골격만 있다.

## 개발

```bash
pnpm install
pnpm dev
```

⚠️ 이 맥은 여러 프로젝트가 포트를 나눠 쓴다. 서버·터널을 띄우기 **전에** 반드시 센다:

```bash
lsof -nP -iTCP -sTCP:LISTEN
docker ps --format '{{.Names}}\t{{.Ports}}'
ps aux | grep -i '[c]loudflared'
```

2026-09-08 기준 `3000 · 3001 · 4000 · 8080`(node)과 `5432`(Docker `booking-db`)가
점유 중이므로 **이 포트들을 피한다.** 남의 프로세스·터널을 끄지 않는다.
