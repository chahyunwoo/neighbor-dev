# apps/web 의존성 선택 근거

## three 는 0.185 다 (0.186 아님) — 2026-09-09 실측

`postprocessing`(=`@react-three/postprocessing` 의 실체)이 아직 0.186 을 지원하지 않는다.

```bash
pnpm view postprocessing@6.39.4 peerDependencies
# → three: '>= 0.168.0 < 0.186.0'
```

기획서 4절이 **데스크톱 포스트프로세싱을 켜는 것으로 확정**했으므로(1차 결정을
뒤집은 것이고 그 근거가 절에 적혀 있다), 포스트프로세싱을 포기하고 three 를
올리는 선택지는 없다. three 를 0.185 로 맞춘다.

→ `postprocessing` 이 0.186 을 지원하면 함께 올린다. 확인:
```bash
pnpm view postprocessing peerDependencies
```

## TypeScript 는 7 이다 (api 와 다르다)

Next.js 는 자체 컴파일러를 쓰므로 TS 7.0 의 컴파일러 API 제거에 영향받지 않는다
(실측: `pnpm build` 통과). `apps/api` 만 TS 6 이다 — 워크스페이스마다 다른 것이 맞다.
자세한 근거는 `apps/api/의존성-메모.md`.
